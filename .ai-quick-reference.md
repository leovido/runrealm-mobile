# AI Agent Quick Reference

> **TL;DR for AI agents**: Quality first, no regressions, minimal changes.

## ⚡ Quick Checklist (Before Every Commit)

```bash
npm run test          # ✅ All tests must pass
npm run lint          # ✅ Auto-fix formatting
npm run build:shared  # ✅ Type checking
```

## 🚫 Three Critical Rules

1. **NEVER remove features** - If it exists, it's probably needed
2. **NEVER make unnecessary changes** - Only change what's requested
3. **NEVER break existing functionality** - Test before committing
