# Ticket: Recent Activity History View

## Summary

Create a dedicated view/screen to display complete activity history, allowing users to browse past runs, achievements, and other activities beyond the recent activity summary.

## Acceptance Criteria

- [ ] New screen/component displays full activity history
- [ ] Activities are sorted by date (most recent first)
- [ ] Support for filtering by activity type (runs, achievements, etc.)
- [ ] Support for pagination or infinite scroll for large history
- [ ] Each activity item shows relevant details (date, distance, duration, etc.)
- [ ] Users can tap activities to view details
- [ ] Empty state when no history exists
- [ ] Integration with UserDashboardService for data fetching
