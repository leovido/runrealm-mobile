# Ticket: AI Insights Dashboard Component

## Summary

Create a dedicated dashboard component to display AI-generated insights including route suggestions, ghost runners, and territory analysis in a user-friendly interface.

## Acceptance Criteria

- [ ] Dashboard component displays AI route suggestions
- [ ] Component displays ghost runner data and comparisons
- [ ] Component displays territory analysis insights
- [ ] Users can interact with insights (accept route, view ghost runner details, etc.)
- [ ] Component handles loading states while AI generates insights
- [ ] Component handles error states gracefully
- [ ] Component updates in real-time when new insights are available
- [ ] Integration with AIService for data fetching
- [ ] Responsive design for mobile and web
